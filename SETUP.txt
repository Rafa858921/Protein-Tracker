PROTEIN TRACKER: iPHONE OFFLINE INSTALL

The iPhone Files app cannot run this calculator's JavaScript. Do not open index.html inside Files.

ONE-TIME WEBSITE SETUP (GitHub Pages):
1. On a computer, sign in to GitHub.com. Create a new PUBLIC repository, for example protein-tracker.
2. Choose Add file > Upload files, then upload index.html, sw.js, manifest.webmanifest, icon-192.png and icon-512.png FROM THIS FOLDER. The files must be in the root of the repository, not nested in the folder. Commit the files.
3. In the repository open Settings > Pages. Under Build and deployment select Deploy from a branch, branch main, folder /(root). Save.
4. GitHub Pages will publish the app to https://YOUR-USERNAME.github.io/protein-tracker/ . It may take a few minutes to publish.
5. On iPhone, visit that exact HTTPS address in Safari while online. Test by editing a number.
6. Tap Safari Share > Add to Home Screen. Turn on Open as Web App if shown and tap Add.
7. Open the new icon once while online so app files can cache. After that it works offline. Try Airplane Mode to confirm.

Protein history is stored on this iPhone, for this web app. It is not synced with other devices and could be lost if Safari website data is cleared or the app is removed. GitHub's public repository will expose the app's code, but not your locally stored personal food history.
